From Learning to Building

How hands-on project engineering transforms technical concepts into practical applications.

Phase 01

Foundations & Core Problem Solving

Began by building a strong foundation in Python, JavaScript, and object-oriented programming concepts. Focused on understanding data structures, algorithmic logic, and writing clean, maintainable code.

Phase 02

Backend Architecture & RESTful APIs

Transitioned to server-side engineering. Explored Node.js and Python (Flask) to build REST endpoints, manage database schemas with MySQL, and implement secure HTTP communication between client and server.

Phase 03

Exploring Artificial Intelligence & Model APIs

Investigated how AI endpoints can be leveraged inside web services. Rather than treating AI as a buzzword, focused on integrating reasoning APIs to address practical tasks such as diagnostic study feedback and automated evaluation.

Unified backend development, database design, and AI APIs into a full-scale real-world project. Currently prototyping student dashboards, timed exam sessions, and automated evaluation pipelines.
